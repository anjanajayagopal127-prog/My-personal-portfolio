- Sky-blue colour palette and clean, friendly design

## Getting started

1. Download or copy `anjana_portfolio.html`.
2. Keep the file and this `README.md` in the same folder if you want to store the project together.
3. Open `anjana_portfolio.html` in a modern web browser.

You can also rename `anjana_portfolio.html` to `index.html` if you want to use it as the default page for a static website host.

## Configure the contact form

The contact form uses an email link. Open `anjana_portfolio.html` in a code editor and find the `SITE_CONFIG` email setting. Replace the placeholder address with your own email address:

```js
SITE_CONFIG.email = "YOUR_EMAIL@example.com";
```

Use an address you want visitors to contact. Test the form after updating it. The visitor's device may open its configured email application when the form is submitted.
